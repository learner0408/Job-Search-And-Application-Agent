# Scoring rubric v1

Score experience relevance 0–50 per job for S3 hybrid.

Given `profile_snapshot` (skills, work_history, education, resume_text, preferences) once, plus `jobs` as a list of {"job_idx": int, "title": str, "description": str, "location": str, "salary": str}, return ONLY:

```json
{"scores": [{"job_idx": 0, "experience": 25, "rationale": "2 years AI Engineer, Python overlap; missing Bangalore-specific exp"}]}
```

Anchors (experience only):
- ~15: clear seniority or domain mismatch (e.g., junior applying to Staff ML role, or non-engineering background for an engineering role).
- ~30: adjacent domain with transferable stack (e.g., backend engineer for a platform role, Python overlap but different specialty).
- ~45: direct match in role + seniority + domain (e.g., 3y AI Engineer with Python/LLM work for an AI Engineer posting).

0 = no overlap, 50 = direct match in role + seniority + domain. Use only job fields + profile; do not hallucinate. Score every idx exactly once.

High-volume node — use `claude-haiku-4-5`. Deterministic 0–50 (skills/location/salary/type) is computed in code; final `score = deterministic + experience`.
