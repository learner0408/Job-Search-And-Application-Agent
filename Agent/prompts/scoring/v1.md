# Scoring rubric v1

Score experience relevance 0–50 for S3 hybrid.

Given `profile_snapshot` (skills, work_history, education, resume_text, preferences) and one job, return ONLY:

```json
{"experience": 25, "rationale": "2 years AI Engineer, Python overlap; missing Bangalore-specific exp"}
```

0 = no overlap, 50 = direct match in role + seniority + domain. Use only job description + profile; do not hallucinate.

High-volume node — use `claude-haiku-4-5`. Deterministic 0–50 (skills/location/salary/type) is computed in code; final `score = deterministic + experience`.
