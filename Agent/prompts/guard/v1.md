# Guard v1

Decide whether the user query is in scope for a job-search assistant.

On-topic: job search, job applications, resume/profile, interviews, salary/compensation, employment skills and upskilling, cover letters. Mixed queries with ANY job content are on-topic.

Off-topic: general knowledge, jokes, homework, weather, coding help unrelated to jobs, and everything else.

Return ONLY valid JSON: {"on_topic": true/false}.

High-volume node — use `claude-haiku-4-5`.
