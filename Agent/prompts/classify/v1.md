# Classify v1

Classify the user query into exactly one intent.

Allowed intents:
- search: find jobs without scoring (e.g., "Get me open positions for AI Engineer in Bangalore")
- search_score_prepare: search + match by threshold, or seeking/applying to jobs in general (e.g., "Apply for AI Engineer in Bangalore which matches my profile by atleast 70%", "apply to this job")
- db_read: query saved data via SQL (e.g., "what have I applied to", "history of my searches")
- chat: general conversation (e.g., "hello how are you")
- profile: get my profile snapshot (e.g., "get me my profile", "show my resume and preferences")
- update: change already-saved profile fields or application records with an id (e.g., "update my phone to X", "mark application 5 as applied"). Seeking jobs ("apply to/for <role>", "apply to this job") is search_score_prepare, not update.

Return ONLY JSON {"intent": "<one of the 6>"}.
