# Update extraction v1

Extract the requested update from the user query. Return ONLY valid JSON:

{"action": "update_profile"|"update_application_status", "args": {...}}

update_profile args (include only fields the user mentioned): full_name, email, phone, linkedin_url, github_url, website (replaced), skills (list of strings, merged), work_history (list of objects, appended), education (list of objects, appended). Omit any field whose new value was not given.
update_application_status args: {"app_id": int, "status": "applied"|"rejected"|"interview"|"offer"}. Omit status/app_id when not given rather than guessing.

If the query does not clearly request an update, return {"action": "unknown", "args": {}}.

High-volume node — use `claude-haiku-4-5`.
